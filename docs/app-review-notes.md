# App Review notes — Kindling 1.0 memory pivot

Kindling 1.0 is a complete product replacement following the previous Guideline 4.3(a) feedback. It is now a private travel-memory app, not a task starter.

No account is required. From onboarding, choose “Explore a sample first” to open a complete Memory Trail built from fictional, app-owned Lisbon media. This path requires no Photos permission.

To test a personal import, choose “Choose a trip.” Kindling uses Apple's system Photos picker and receives only the items the reviewer selects; it does not request full-library access. Selected images and videos are optimized into app-owned local copies, grouped into editable moments, and presented as an autosaved draft.

The first complete Memory Trail never encounters a paywall. Free users can save two personal trips. Attempting to save a third personal trip presents Kindling Pro. The bundled sample does not count toward the limit. Restore Purchases is available both on the paywall and in Settings.

All imported media, notes, tags, voice notes, search data, privacy flags, and generated sharing artifacts stay on the device. Analytics contains only fixed event names and coarse numeric buckets; it never receives trip titles, places, notes, tags, media identifiers, coordinates, or filenames.

This build intentionally contains no AI feature, widget, Live Activity, broad Photos access, iCloud sync, automatic trip discovery, or animated recap. Those capabilities are not advertised.
